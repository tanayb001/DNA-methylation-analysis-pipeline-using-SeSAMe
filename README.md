# SeSAMe DNA Methylation Analysis Pipeline

A configurable pipeline for DNA methylation array analysis using SeSAMe, R/Bioconductor, and Python. It covers IDAT preparation, quality control, methylation preprocessing, exploratory analysis, differential methylation, annotation, and pathway enrichment.

## Features

- IDAT preparation and validation
- Sample-level quality control using detection metrics
- SeSAMe-based methylation preprocessing and beta-value extraction
- PCA, UMAP, beta-value distributions, and variable-probe heatmaps
- Differential methylation analysis between user-defined groups
- Probe and gene annotation with volcano plots
- Pathway over-representation and gene set enrichment analysis
- Lollipop plots for pathway results

## Requirements

- R and R/Bioconductor
- Python 3
- SeSAMe and its required annotation resources

Install the Python dependencies using `requirements.txt` and the R/Bioconductor dependencies using `scripts/00_install_dependencies.R`.

## Input Data

Place paired red and green IDAT files in `data/raw/`.

Create a sample sheet by copying the example template:

```bash
cp metadata/sample_sheet.example.csv metadata/sample_sheet.csv
```

Edit the file for your dataset. The default sample sheet contains three columns:

| Column | Description |
|---|---|
| `sample_id` | Sample identifier matching the IDAT filename prefix |
| `patient` | Biological unit identifier; technical replicates from the same patient share an identifier |
| `group` | Sample group used for comparisons |

Sample IDs and group labels must match the corresponding IDAT files and configuration settings.

## Configuration

Create a local configuration file:

```bash
cp config/config.example.yaml config/config.yaml
```

Edit `config/config.yaml` to specify the input paths, sample-sheet location, comparison groups, quality-control thresholds, preprocessing options, and analysis settings.

The example configuration uses `hg38` and automatic array-platform detection. Downstream annotation is currently configured for hg38, so check that the settings are appropriate for your data.

## Running the Pipeline

Install the dependencies:

```bash
python3 -m pip install -r requirements.txt
Rscript scripts/00_install_dependencies.R
```

After preparing the IDAT files, sample sheet, and configuration, run:

```bash
bash run_pipeline.sh
```

The pipeline runs the following steps in sequence:

1. **IDAT preparation** — prepare and validate input files.
2. **Quality control** — assess sample-level detection metrics.
3. **Methylation preprocessing** — process IDATs and generate beta values.
4. **Exploratory analysis** — generate beta-value distributions, PCA, and heatmaps.
5. **UMAP** — visualize sample-level methylation patterns.
6. **Differential methylation** — compare the configured case and reference groups.
7. **Annotation and volcano plots** — annotate differential methylation results.
8. **Pathway analysis** — perform over-representation analysis and gene set enrichment analysis.
9. **Lollipop plots** — visualize selected pathway results.

## Outputs

Results are written to the configured results directory, which defaults to `results/`.

The pipeline generates QC reports, processed beta values, exploratory plots, differential methylation tables, annotated probe and gene results, volcano plots, pathway enrichment tables, and figures.

## Example Figures

The `examples/figures/` directory contains representative outputs from the pipeline, including QC plots, beta-value distributions, replicate concordance, PCA, UMAP, a variable-probe heatmap, and volcano plots.

These figures illustrate the available visualizations; they are not regenerated by cloning the repository.

## Notes

- Review the configuration and quality-control thresholds before analyzing a new dataset.
- Results depend on the input data, sample annotations, software versions, and analysis settings.
- Do not commit raw IDAT files, confidential sample metadata, local configuration files, or private analysis outputs. Check the staged files before committing.
